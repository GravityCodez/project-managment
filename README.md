# ClassMic

BUS 2010 Project Management coursework by **Temiko Machavariani** and **Nurtore Arynuruly**. ClassMic explores instructor-controlled phone microphones for classroom discussion through a small browser prototype.

## Start here

1. Read [current status](docs/STATUS.md) and [deadlines](docs/DEADLINES.md).
2. Read the [agent and teammate handoff](docs/AGENT_HANDOFF.md), then follow [collaboration instructions](CONTRIBUTING.md) and the repo-wide [working agreements](AGENTS.md).
3. Use the [file index](docs/INDEX.md) to find the assignment you need.

| Folder | Purpose |
| --- | --- |
| submissions/initial-phases/ | Refreshed A2 aspiration, B2 business case and C1 charter |
| submissions/lab-2026-09-17/ | ABCDEF WBS and linked schedule lab |
| working/phase-d/ | Earlier planning drafts retained for future work |
| references/ | Original course briefs and genuine team input |
| docs/ | Team facts, decisions, deadlines, evidence status and indexes |
| scripts/ | Release checks and artifact builders |
| archive/ | Older versions retained for traceability |

Only the assignment-specific files in `submissions/` are intended for coursework handoff. Internal records belong in `docs/`. Submission readiness and actual LMS submission are tracked separately.

The selected scope is five user stories, two weekly sprints, 100 estimated student hours and AED 0 incremental cash conditional on available resources. See [decisions](docs/DECISIONS.md) for qualifications and source history.
