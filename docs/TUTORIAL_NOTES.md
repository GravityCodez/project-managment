These notes summarize the spoken instructions; the machine transcript can contain recognition errors.

- 00:16–00:42: replace the example project name with the team's own project; make it the root of the WBS.
- 00:42–02:51: indent activities beneath their phase summaries. Place two sprint activities under execution. The example groups A/B as pre-initiation, then C charter, D planning, E execution and F finish.
- 02:51–03:55: create predecessor links to connect the work. The demonstration links phase summaries; the lab text also permits work-package links.
- 03:55–04:27: check the resulting start and finish dates. This exercise concerns decomposition and sequencing; cost estimation comes later.
